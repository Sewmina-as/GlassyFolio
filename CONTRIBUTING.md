# Contributing

Thank you for your interest in contributing to this portfolio template! 🎉

## How to Contribute

1. **Fork** the repository
2. **Clone** your fork locally
3. Create a **feature branch** (`git checkout -b feature/amazing-feature`)
4. **Commit** your changes (`git commit -m 'Add amazing feature'`)
5. **Push** to the branch (`git push origin feature/amazing-feature`)
6. Open a **Pull Request**

## Development Setup

```bash
# Install dependencies
npm install

# Start dev server
npm run dev

# Type-check
npm run type-check

# Lint
npm run lint
```

## Guidelines

- Keep the template simple and customizable
- Ensure all changes work on mobile devices
- Respect `prefers-reduced-motion` for animations
- Maintain TypeScript strict mode
- Test across modern browsers (Chrome, Firefox, Safari, Edge)

## Reporting Issues

- Use the GitHub issue tracker
- Include browser/OS info for visual bugs
- Include screenshots when relevant

## Code Style

- Use TypeScript for all source files
- Follow existing naming conventions
- Keep components focused and small
- Comment complex logic
